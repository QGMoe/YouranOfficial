# 悠然服务器 {: #hero-title }

## 简介 {: .intro-label }

我们是一个拥有近百个模组以及一些插件的 Minecraft Java 1.12.2 SpongeForge 公益养老服，最开始仅仅是一个原版纯生存服务器，后来开始装模组甚至 SpongeForge 插件。

服务器始于 2021 年，但在 2024 年 7 月底，悠然 MC 服务器暂时关闭，但已于 2026 年 6 月重新开启！目前，我们的服务器位于江苏，由旋律云提供。

服务器从始至终完整保留存档和各类玩家数据。因此，随着时间的推移，各类玩家逐渐在服务器中留下属于他们自己的痕迹。这让服务器有一种神秘感（比如是谁乱丢一大堆岩芯样本的 awa）。
